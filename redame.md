# Transposon Tools Atlas

An interactive, curated index of software for studying transposable elements (TEs), also called transposons, across five species:

- Human
- Mouse
- Plant
- Zebrafish
- *Drosophila melanogaster*

**Live site:** https://sugam2001.github.io/Transpososn-Tool-Atalas/

Browse the tools by species, or by the question they answer: genome annotation, family-level and locus-level RNA-seq, single-cell RNA-seq, long-read insertion discovery, ChIP-seq and ATAC-seq at repeats, and Hi-C. Each entry links to its reference paper and, where available, its code.

## Contents

- `index.html`: the atlas page (a single file, no installation needed)

## Adding or correcting a tool

Open an issue or pull request with:

1. The tool name
2. The species it supports
3. The reference paper (DOI or link)
4. The code repository link, if it has one

## Scope and limitations

Some categories are still incomplete, including fusion detection involving TEs, Drosophila piRNA tools, short-read insertion callers, zebrafish-specific tools, and plant isoform-level tools. Contributions are welcome.

## Citation

If you use this atlas in your work, please cite the individual tools listed on the page, not the atlas itself.
